# ABB Type F RCCB reference

Reference facts for distinguishing Type F residual-current devices from simpler waveform classes.

- The extra capability of Type F beyond Type A is detection of residual currents from mixed frequencies up to 1000 Hz.
- ABB describes Type F devices as providing the Type A range of protection: sinusoidal AC and pulsating DC residual-current detection.
- These mixed-frequency currents can occur downstream of some single-phase frequency converters.
- Type F is therefore not simply another name for Type AC. The exact product type and installation application must be checked before substitution.
