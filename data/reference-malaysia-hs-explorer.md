# Malaysia Customs HS Explorer reference

Reference facts for the Royal Malaysian Customs Department's JKDM HS Explorer.

- JKDM HS Explorer is intended to help users search tariff rates for products of interest.
- The tool uses selections such as tariff type and search criteria; the result depends on the product classification and the selected tariff arrangement.
- A product SKU or marketing name is not, by itself, an exact HS code. Do not state a tariff code without the relevant customs classification and applicable tariff context.
- Use the official customs tool or obtain a customs ruling when an exact classification matters.

Source: https://ezhs.customs.gov.my/public-home
