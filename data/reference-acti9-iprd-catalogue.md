# Acti9 and KQ iPRD F40r surge-protection catalogue

Source: Schneider Electric, [Acti9/KQ SPD Plug and Play Catalog](https://www.se.com/in/en/download/document/CA903020/), document CA903020.

This is a source digest of the manufacturer catalogue for Acti9 and KQ iPRD F40r surge protection. It is not a SupplierFlow stock list or a promise that a particular cartridge is available locally. Exact compatibility must be checked against the original catalogue and board system.

Quick answer: the covered network systems are TT, TN-S and TN-C-S. A Type 3 cartridge cannot replace a Type 2 iPRD device unless the exact replacement cartridge is compatible with that device family.

## Product scope

The catalogue presents iPRD F40r surge-protection solutions for residential, commercial and industrial buildings. It covers Type 2 and Type 3 SPD solutions and gives commercial references, technical specifications, installation features, performance data, dimensions and compliance information.

The catalogue names references such as A9L8F451, A9L8F461, SEL8F450 and SEL8F460, together with replacement cartridges A9L8F492 and SEL8F492. A cartridge reference is not automatically the same thing as a complete SPD assembly. Keep the complete-device reference and replacement-cartridge reference separate.

## Network systems and boards

The covered products are intended for 230/400 V networks with TT, TN-S and TN-C-S earthing systems. The network system is a selection input, not an afterthought. A device selected for one wiring arrangement should not be presented as universally correct for all TT, TN and IT installations.

The solutions are designed for Isobar P distribution boards and KQ loadcentres. Board compatibility includes physical fit, connection arrangement and the intended protection scheme. A technically similar SPD can still be the wrong product for a particular board or enclosure.

## What surge protection addresses

The catalogue describes protection against induced or conducted surges caused by direct and indirect lightning events. A surge-protection device limits transient overvoltage by diverting surge current through its protective path. It is not a replacement for an MCB, RCCB, fuse, isolator or earthing system.

The terms Type 2 and Type 3 indicate roles in a coordinated protection arrangement. A Type 2 device is normally used at distribution level. A Type 3 device is used close to sensitive equipment when the installation design calls for additional local protection. The exact siting and coordination rules must be followed.

## Plug-and-play features

The F40r solutions are described as plug-and-play products with embedded self-protected backup fusing, end-of-life remote signalling and replaceable cartridges. These features help maintenance and status indication. They do not mean that every installation can omit upstream isolation or that a failed cartridge can be replaced with any cartridge of a similar colour or kA label.

Remote signalling is a status output. It is not a measurement of the remaining surge capacity and it should not be described as a live energy-monitoring channel. A customer asking about “alarm output” should be answered with the catalogue’s end-of-life signalling information.

## Reading an SPD reference

An SPD reference should be read with its type, network arrangement, number of protected conductors, nominal operating voltage, discharge-current ratings, backup protection and board compatibility. The voltage and earthing system are as important as the headline kA number.

The same family may have 1P, 1P+N, 3P or 3P+N forms. Pole count changes which conductors are protected and how the device is wired. It is unsafe to choose a 1P device simply because the customer says “single phase”; the neutral and earthing arrangement still matter.

## Replacement and maintenance

Replaceable cartridges are useful only when the replacement reference is compatible with the base device. The assistant should verify family, board system and cartridge type before saying that a spare fits. If the source only lists a reference but not a local price or stock status, those commercial fields must be refused or routed to sales.

## Answering rule

For a product-selection question, return the exact family and reference supported by the source, then identify the missing installation inputs. Do not map “surge protector” to an MCB or RCCB. Those devices may be used in the same board, but their protective functions are different.
