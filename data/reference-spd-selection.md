# SPD selection reference

Reference facts for understanding low-voltage surge-protective-device (SPD) types. These notes do not establish SupplierFlow delivery, pricing, or installation policy.

- An SPD limits transient overvoltage and diverts surge energy to help protect an electrical installation and connected equipment.
- Type 1, Type 2, and Type 3 are different SPD classes with different installation roles and discharge capabilities; the correct type depends on the installation conditions and protection requirements.
- A Type 2 SPD is installed on the load side of the main service overcurrent protective device and needs appropriately rated upstream overcurrent protection coordinated with the manufacturer's instructions.
- A Type 3 SPD provides local protection for sensitive loads and is installed near the load. Schneider's guidance says it should be used to complete Type 2 protection and located within 10 m of the sensitive load in the described arrangement.
- The associated fuse or circuit breaker must be selected from the SPD manufacturer's coordination guidance and the short-circuit conditions at the installation site.
