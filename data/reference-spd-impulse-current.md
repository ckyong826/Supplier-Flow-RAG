# SPD impulse-current waveform reference

Reference facts for separating Type 1 impulse current from Type 2 maximum discharge current.

- For a Type 1 SPD, Iimp is the maximum discharge current for the 10/350 microsecond impulse wave; Schneider's FAQ describes the cited device test as five discharges.
- For a Type 2 SPD, Imax is the maximum discharge current for the 8/20 microsecond impulse wave; the cited guidance describes it as withstandable at least once.
- Iimp and Imax are different ratings with different waveforms and test duties. Do not compare their numeric values as if they were the same specification.

Source: https://www.se.com/th/en/faqs/FA346673/
