# Acti9 iC60 RCBO installation-sheet reference

Source: Schneider Electric, [Acti9 iC60 RCBO instruction sheet](https://download.se.com/files?p_Doc_Ref=D384245&p_File_Name=D384245-00.pdf&p_enDocType=Instruction+sheet), document D384245.

This reference digest explains what an installation sheet contributes beyond a catalogue entry. It is not a SupplierFlow price, stock, delivery, warranty or installation approval. The original Schneider instruction sheet controls the field procedure.

Quick answer for document D384245: VISI-SAFE is a visual contact-status feature; it does not prove the circuit is dead and does not replace isolation and a voltage test.

## Why an instruction sheet is different

A catalogue helps select a product. An instruction sheet explains how to mount, connect and operate that product. Those are different evidence types. A product catalogue may tell us that an RCBO exists with a particular current and sensitivity; the instruction sheet is the source to use for terminal identification, mounting direction, test operation and installation warnings.

The cited sheet is for an Acti9 iC60 RCBO. It identifies the DIN-rail mounting clip, power-supply terminals, QR code for maintenance information, VISI-SAFE positive contact indication and the test button. These labels help an installer identify the device features without treating every visual marking as an electrical rating.

## DIN-rail mounting

The RCBO is a modular device intended for a distribution-board installation. The mounting clip is part of the mechanical interface with the DIN rail. Correct mounting requires a suitable rail, stable seating and the clearances required by the product instructions.

Mechanical attachment is not the same as electrical connection. A device can appear to clip onto a rail while still being incorrectly wired. The assistant should answer mounting questions with the instruction sheet and should not infer terminal polarity or supply direction from a product photograph.

## Supply terminals and conductors

The sheet identifies power-supply terminals as a product feature. The exact terminal numbers, allowable conductor sizes, torque and supply direction must be read from the actual diagram and product variant. A family-level answer such as “connect the line anywhere” is unsafe.

The line, neutral and load conductors must follow the product’s wiring diagram. An RCBO measures residual current through the conductors that belong to its protected circuit. A neutral borrowed from another circuit can create unwanted trips or defeat the intended sensing arrangement.

## Positive contact indication

VISI-SAFE is described on the sheet as positive contact indication, including full opening of the poles. This is a visual status feature. It should not be confused with proof that the circuit is dead, proof that downstream conductors are safe to touch, or proof that the installation has passed an insulation test.

Before work, the installer still follows the isolation and verification procedure required by local rules. A visual indicator supports identification; it does not replace a voltage test.

## Test button

The test button checks the RCBO’s residual-current trip function under the conditions defined by the manufacturer. It is not a substitute for a complete commissioning test. The device must be supplied and wired according to the sheet for the test to be meaningful.

If the test button does not operate, do not bypass it or continue using an unverified protective device. Check the wiring, supply, product variant and instruction. If the issue remains, stop and use a qualified electrician or manufacturer support.

## QR code and maintenance

The QR code shown on the sheet is for maintenance information. A QR code is not an electrical communication protocol and it does not change the trip curve, sensitivity or breaking capacity. When a customer asks what the QR code does, the supported answer is maintenance or product information.

## Product and instruction boundaries

The instruction sheet covers installation features but does not prove the commercial availability of a product. It also does not turn one iC60 RCBO into a substitute for a different current, curve, pole or breaking-capacity variant.

For an exact product request, combine the catalogue row with the installation sheet. Keep the product identity, wiring instructions and operational-status features as separate evidence. If the requested terminal or torque value is not visible in the retrieved text, abstain instead of guessing.
