# TeSys D linked-contact reference

Reference facts for mechanically linked and mirror contacts on Schneider TeSys D contactors.

- Schneider states that TeSys D contactors from LC1D09 up to LC1D150 include mirror contacts and mechanically linked contacts.
- These contact properties matter when monitoring the state of power contacts or using the device in a safety-related circuit.
- The exact auxiliary arrangement and terminal assignment still require the wiring diagram for the requested SKU.

Source: https://www.se.com/us/en/faqs/FA126437/
