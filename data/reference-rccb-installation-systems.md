# RCCB installation-system reference

Reference facts for the operating principle and installation-system boundary of an RCD/RCCB.

- For an earth fault, an RCD detects an unbalanced current between the phase conductor and the neutral conductor; the imbalance can be caused by phase current leaking to ground.
- ABB's guide notes that the residual-current operating principle is not suitable for a TN-C system when the neutral is also used as the protective conductor.
- Type A is intended for AC and specified pulsating DC residual current, including circuits where the supply is likely to be rectified. Confirm the exact device type and local installation requirements before selection.
